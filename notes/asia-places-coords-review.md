# Timeline Asie : points approchés pour les régions et sites

**À vérifier :**

1. Régions (Java, Aceh, Bengale, Santal Parganas, Nadia, île de Ganghwa, Malabar, Nghệ An, Luçon central, Corée, Télangana, Jeju, Kerala, Cachemire, Pendjab, Gujarat, Arakan, Mullaitivu) : point représentatif choisi de mémoire.
2. Le Bengale et le Pendjab sont des régions historiques aujourd'hui partagées entre deux États ; le code pays retenu (IN pour le Bengale, PK pour le Pendjab) est conventionnel.
3. Sites dont la position exacte reste à vérifier : mine de cuivre d'Ashio, Rana Plaza (Savar), Uraga.
4. Cavite sert aussi pour la déclaration d'indépendance de Kawit (1898) ; Jeongeup pour le soulèvement de Gobu (1894) ; Srirangapatna, Tharrawaddy et Yenangyaung sont des points de mémoire.
