# Nomination de Suárez : date à vérifier

**À vérifier :** *Spanish transition to democracy* donne le 1er juillet 1976 dans sa chronologie et le 3 juillet dans le texte. Usuellement : démission d'Arias Navarro le 1er juillet, nomination de Suárez le 3.

**Choix retenu :** 3 juillet 1976.
