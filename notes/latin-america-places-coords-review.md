# Timeline Amérique latine : points approchés

**À vérifier :**

1. Pays et régions (Mexique, Argentine, Bolivie, Pérou, Colombie, Équateur, Paraguay, Uruguay, Honduras, Yucatán, Chiapas, Morelos, Santa Cruz, Araucanie, Chaco boréal, Pará) : point représentatif choisi de mémoire.
2. Canudos : point de Nova Canudos ; l'ancienne ville est noyée sous le réservoir de Cocorobó, dont la position n'a pas été vérifiée.
3. Chinameca, Dos Ríos, Vertières, Playa Las Coloradas : les pages consultées ne donnent pas de coordonnées ; points estimés (Dos Ríos près de Palma Soriano, Vertières au sud de Cap-Haïtien, Las Coloradas dans la commune de Niquero).
4. Iguala : la page *Iguala mass kidnapping* donne 17,55 N, 99,41 O, qui semble correspondre à Ayotzinapa (Tixtla) et non à Iguala ; le point d'Iguala (18,35 N, 99,54 O) est de mémoire.
5. Izalco, Eldorado do Carajás (route PA-150), Pulacayo, Cascavel, São Bernardo do Campo et la place de Mai : points de mémoire.
6. Massacre de l'école Santa María : le lieu `iquique` reprend les coordonnées de l'école données par la page consultée.

**Choix retenu :** points enregistrés ; à affiner si la carte l'exige.
