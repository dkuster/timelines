# Bios des personnes les plus citées : faits non relus sur la source

Les 19 bios ajoutées le 25 octobre 2026 s'appuient sur la page Wikipedia anglaise citée en source. Les faits suivants n'y figuraient pas (ou pas dans la partie consultée) et reposent sur le consensus :

- **Lénine** : arrestation fin 1895 ; fondation de l'Internationale communiste en 1919.
- **Staline** : séminaire de Tiflis ; famines liées à la collectivisation (ampleur non chiffrée).
- **Trotski** : rôle d'organisateur de l'insurrection d'Octobre via le Comité militaire révolutionnaire (présidé formellement par Lazimir).
- **Mussolini** : émigration en Suisse (1902-1904) ; assassinat de Matteotti (1924).
- **Napoléon** : répression de Vendémiaire (1795) ; Code civil de 1804 ; rétablissement de l'esclavage en 1802.
- **Napoléon III** : insurrections italiennes de 1831 ; Sedan le 2 septembre et déchéance le 4 septembre 1870.
- **Franco** : désignation de Juan Carlos en 1969.
- **Poutine** : famille ouvrière ; seconde guerre de Tchétchénie lancée en 1999.
- **Nicolas II** : prise du commandement suprême en 1915 ; date d'abdication 2 (15) mars 1917 ; pogroms des Cent-Noirs.
- **De Valera** : professeur de mathématiques ; neutralité pendant la Seconde Guerre mondiale.
- **Alexandre II** : nombre de serfs libérés (« plus de vingt millions ») ; projet Loris-Melikov approuvé le jour de l'attentat.
- **Victor-Emmanuel III** : signature des lois raciales de 1938 ; assassin de son père (Bresci).
- **Garibaldi** : citation sur l'Internationale « soleil de l'avenir » (rapportée par la page, sans référence primaire vérifiée).
